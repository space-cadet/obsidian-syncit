## What Was Done

ETag support added to WebDAVAdapter. ETags are now captured during PROPFIND and stored in `FileEntity.etag`. This enables T12d (Local Sync Index) to use ETags as the authoritative signal for "unchanged" files.

Full conflict resolution UI (modal with keep-local/keep-remote/keep-both options) is **not yet implemented** — the current behavior still uses "newer wins" for conflicts. The remaining conflict, move, and shared-baseline work is now tracked in T13.

## Notes
- ETags are more reliable than timestamps alone
- T12d's SyncIndexManager uses ETags to skip unchanged files (no network round-trip)
- Mobile users especially need conflict resolution — they edit offline frequently
- ETags alone do not provide cross-device deletion history; T13 adds the shared manifest and tombstones needed for new-device reconciliation.
