# T4: Conflict Resolution with ETags

*Created: 2026-08-17 14:20 IST*

**Status**: 📋 **PLANNED**
**Priority**: P0 (User's #1)

## Details

Implement conflict detection and resolution using ETags for automatic conflict detection. Currently the plugin uses "newer wins" silently, which can cause data loss.

## Goals

1. **ETag-based conflict detection**: Use WebDAV ETags to detect when a file has changed on both sides since last sync
2. **Automatic conflict resolution**: When ETags mismatch and timestamps are close, flag as conflict
3. **Conflict resolution UI**: Modal showing local vs remote content with options:
   - Keep local
   - Keep remote
   - Keep both (auto-rename with timestamp)
   - Skip this file
4. **Conflict file storage**: Save conflict versions to `.syncit-conflicts/` for manual review
