# T12a: Fix PROPFIND — Recursive File Listing

## Problem

`WebDAVAdapter.listFiles()` called `propfind(this.baseDir, 1)` with `Depth: 1`. This only listed immediate children. Files in subdirectories were completely invisible to the sync engine.

## Solution Implemented

1. **Try `Depth: infinity` first** — single PROPFIND request gets the entire tree. Most servers (Nextcloud, ownCloud, Apache mod_dav) support this.
2. **Graceful fallback** — if server returns 403/400/501, automatically falls back to recursive `Depth: 1` directory walk.
3. **Directory filtering** — both paths filter out directories (no `<D:getcontentlength>` or path ends with `/`).

## Changes

- `src/remote/WebDAVAdapter.ts`:
  - `listFiles()` — now tries infinity depth first, then recursive fallback
  - Added `listFilesRecursive()` — BFS directory walker using `Depth: 1`
  - Added `filterFileEntities()` — shared filtering logic
  - `propfind()` — accepts `depth: number | "infinity"`
