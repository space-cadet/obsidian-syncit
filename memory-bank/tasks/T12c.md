# T12c: Batch MKCOL — Eliminate Redundant Directory Creation

**Status**: ✅ COMPLETE
**Priority**: P1
**Parent**: T12
**Created**: 2026-08-17
**Completed**: 2026-08-17

## Problem

`WebDAVAdapter.writeFile()` called `mkcol()` for every file's parent directory, even if that directory was just created for the previous file. For 50 files in the same directory, that's ~100 redundant MKCOL requests (most returning 405 "already exists").

## Solution Implemented

Added a `createdDirs: Set<string>` to track directories created during the current session. Before calling `mkcol()`, check the set — skip if already created.

## Changes

- `src/remote/WebDAVAdapter.ts`:
  - Added `createdDirs = new Set<string>()`
  - `writeFile()` — checks set before `mkcol()`, adds after success
  - `disconnect()` — clears the set
