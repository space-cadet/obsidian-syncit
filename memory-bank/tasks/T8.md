## Details

Preview what a sync would do without actually doing it. Builds trust and prevents surprises.

## Goals

1. **"Preview Changes" button**: In settings and sidebar
2. **Show sync plan**: List all files that would be uploaded/downloaded/deleted
3. **Diff preview**: Show content differences for modified files
4. **Confirm before apply**: After preview, user clicks "Apply" or "Cancel"
5. **Modal UI**: Clean list of pending changes with icons
