## Description

Preview what a sync would do without actually doing it. Builds trust and prevents surprises.

## Completion Criteria

- [x] `performDryRun()` — scans, builds plan, shows preview, zero transfers
- [x] "Dry Run" button in sidebar (2x2 grid layout)
- [x] Command Palette command for dry run
- [x] `showDryRunResult()` displays 🧪 preview cards with plan summary
- [x] Debug logging writes to `.obsidian/plugins/obsidian-syncit/debug.log`
- [x] Artificial 20ms per-file delay removed — now instant after scan

## What Was Built

### `performDryRun()`
- Phase 1 (Scan): Lists local + remote files via VaultScanner + WebDAVAdapter
- Phase 2 (Compare): Builds sync plan, skips Phase 3 (Transfer)
- Zero actual transfers — purely informational

### `showDryRunResult()`
- Displays 🧪 preview cards showing what would happen
- Shows upload/download/delete counts and byte totals
- No confirmation/apply step — preview only (user can run real sync after)

### Sidebar Integration
- "Dry Run" button added to 2x2 action grid alongside Sync Now, Settings, Rebuild Index
- Scan spinner (`setScanning()`) shows "⏳ Scanning..." during scan phase

### Debug Logging
- `DebugLogger` class writes to `debug.log` in plugin directory
- Replaces console logging for production builds
- Logs all dry run steps for troubleshooting

## Related Files
- `src/main.ts` — `performDryRun()` method, command registration
- `src/ui/SyncSidebarView.ts` — dry run button, scan spinner, result display
- `src/sync/SyncPlan.ts` — plan building reused for dry run
- `src/sync/DebugLogger.ts` — debug log file writer

## Notes
- Dry run loads the sync index; if index is missing, ALL files appear as changes (this was the root cause of the "1710 downloads" apparent bug — the index was being wiped by `saveSettings()`, see edit 2026-08-18 fd784b2)
- Diff preview for text files was planned but not implemented
- Confirm-before-apply flow was planned but not implemented (dry run is preview-only)
