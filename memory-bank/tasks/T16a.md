# T16a: Redesign Sync Sidebar

*Created: 2026-09-01 22:45 IST*
*Last Updated: 2026-09-01 22:45 IST*

**Status**: ✅ **IMPLEMENTED — manual narrow-pane acceptance remains with T16d**
**Parent**: T16 (SyncIt UI Redesign and Error Observability)
**Priority**: P1

## Objective

Turn the Sync sidebar into the compact control surface shown in the approved mockup.

## Required Areas

- Navigation that clearly separates Sync, Activity, Errors, and Settings.
- Connection/status card with current state and last sync result.
- Segmented sync direction control for Download, Bidirectional, and Upload.
- Files-to-sync summary with counts and conflict/error emphasis.
- Advanced options that do not compete with the primary action.
- One prominent Sync action and a compact recent-activity summary.
- Fixed connection information at the bottom where space permits.

## Acceptance Criteria

- [x] The main action and current sync direction are immediately identifiable.
- [x] Error counts are actionable and open the Errors surface.
- [ ] The layout remains readable in a narrow sidebar without overlapping controls; real-device verification remains with T16d.
