# T16b: Redesign Reconciliation Review

*Created: 2026-09-01 22:45 IST*
*Last Updated: 2026-09-01 22:45 IST*

**Status**: 🔄 **PLANNED**
**Parent**: T16 (SyncIt UI Redesign and Error Observability)
**Priority**: P0 (data-safety UI)
**Dependencies**: T13

## Objective

Present ambiguous files as a clear review table that supports safe decisions without hidden or overlapping controls.

## Required Areas

- File/path column with safe truncation and accessible full names.
- Reason/status column explaining the ambiguity.
- Action column with an explicit per-file decision.
- A single scrollable file table/list.
- Fixed Cancel and Apply decisions actions outside the list.
- Clear unresolved count and disabled Apply state.

## Acceptance Criteria

- [ ] All reconciliation rows remain reachable at narrow and tall list sizes.
- [ ] Cancel and Apply remain visible while the file list scrolls.
- [ ] The review explains why each action is available and what it will do.
- [ ] Apply remains blocked until every required decision is resolved.
