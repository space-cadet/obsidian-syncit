# T6: Selective Sync

*Created: 2026-08-17 14:20 IST*

**Status**: 📋 **PLANNED**
**Priority**: P1 (User's #3)

## Details

Allow users to pick specific folders to sync rather than syncing the entire vault.

## Goals

1. **Folder picker in settings**: UI to select which folders to include/exclude
2. **Per-folder sync**: Only sync files within selected folders
3. **Override global patterns**: Selected folders can override global exclude patterns
4. **Visual indicators in sidebar**: Show sync status per folder

## Subtasks

- [ ] Add folder list to settings UI
- [ ] Modify VaultScanner to respect selected folders
- [ ] Add "Selective Sync" section to settings
- [ ] Show included folders in sidebar
- [ ] Handle folder renames/moves gracefully

## Files to Modify
- `src/settings.ts` — Add folder picker UI
- `src/local/VaultScanner.ts` — Respect selected folders
- `src/types.ts` — Add selective sync settings

## Notes
- Default: sync everything (backward compatible)
- Use Obsidian's folder structure for the picker
- Important for vaults with large attachments in some folders
