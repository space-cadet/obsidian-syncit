# T16c: Proper Activity and Errors Log Viewer

*Created: 2026-09-01 22:45 IST*
*Last Updated: 2026-09-01 22:45 IST*

**Status**: 🔄 **PLANNED**
**Parent**: T16 (SyncIt UI Redesign and Error Observability)
**Priority**: P0 (failure diagnosis)
**Dependencies**: T5a, T5b, T5c

## Objective

Replace the current decorative log cards with a functional log viewer that helps users find, inspect, and act on failures.

## Required Areas

- Activity view for sync sessions and operations.
- Errors view showing persisted per-file failures and the total for the selected run.
- Columns or aligned fields for timestamp, level, category, operation, path, and message.
- Search, level, session, and time filters with clearly documented semantics.
- Expandable structured details and safe copy-to-clipboard support where available.
- Load-more/pagination or equivalent bounded rendering for large logs.
- Empty, loading, parse-error, rotation, and auto-refresh states.

## Acceptance Criteria

- [ ] The 272-error scenario displays individual error records, not only a summary count.
- [ ] Selecting All shows every persisted level; selecting Error shows failures according to documented filter behavior.
- [ ] The viewer does not load an unbounded log file into the DOM.
- [ ] Auto-refresh preserves filters and does not unexpectedly move the user’s scroll position.
- [ ] Sensitive values are not shown in rendered details.
