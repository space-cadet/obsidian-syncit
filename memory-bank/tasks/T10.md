## Current Thinking

### Trash Mode
- Deleted locally → move to `.syncit-trash/` on remote (not permanent delete)
- Deleted remotely → move to local `.trash/` (Obsidian's system trash)
- Configurable: "trash" (default) vs "permanent" vs "ignore deletes"
- Trash retention: 30 days, then auto-purge
- Remote trash must use WebDAV `MOVE` into a run-specific `.syncit-trash/` path; permanent `DELETE` requires explicit opt-in.
- `confirmBeforeDelete`, `moveToTrash`, and an `ignore` policy must be enforced by the plan executor, not only exposed in settings.
- T13 uses local trash/review archival for stale local-only files during Remote wins reconciliation.

### Snapshots
- Before any sync, copy files that will be modified to `.syncit-snapshots/YYYYMMDD-HHMMSS/`
- Keep last N snapshots (configurable, default 10)
- One-click restore from sidebar
- Auto-purge old snapshots
