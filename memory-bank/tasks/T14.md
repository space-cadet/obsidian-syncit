## Goal

Replace the simple "Sync Now" button with a sync direction dropdown and add default policy settings to the Settings UI. This makes sync direction explicit and eliminates friction for common use cases (backup vs. sync vs. restore).

## Background

T13 implemented a reconciliation panel for ambiguous sync situations, but it adds complexity for users who just want a simple "push to server" or "pull from server" workflow. The reconciliation panel will be temporarily disabled in favor of explicit sync directions, then brought back later with proper default policies.

### T14d: Make `buildPlan()` respect sync direction ✅
- Upload-only: skip all downloads, only process uploads
- Download-only: skip all uploads, only process downloads

### T14e: Orphan file policies ✅
- `downloadOrphanPolicy`: "keep" | "delete-local"
- `uploadOrphanPolicy`: "keep" | "delete-remote"
- Controls what happens to files that exist on one side but not the other during one-way sync
- "keep" = leave them alone (safe default)
- "delete" = mirror mode, delete orphans to match the source

- Background, border, hover, focus states match the app
- No more ugly white browser-native selects

### T14g: Dry run integration ✅

- Shows full preview instead of stopping at reconciliation panel
- Accepts optional mode parameter for direction-specific dry runs
