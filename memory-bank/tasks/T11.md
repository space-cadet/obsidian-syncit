# T11: Chunked Downloads

*Created: 2026-08-17 14:20 IST*

**Status**: 📋 **PLANNED**
**Priority**: P2 (User's #8)

## Details

Support downloading large files in chunks with resume capability. Currently files are downloaded in one request which may fail for large attachments.

## Goals

1. **Chunked downloads**: Split large files into chunks (e.g., 5MB)
2. **Resume support**: If download fails, resume from last chunk
3. **Progress tracking**: Show per-file progress for large downloads
4. **Size threshold**: Only chunk files above certain size (configurable)
