## Workflow Behavior

| Trigger | Workflow | Result |
|---------|----------|--------|
| Push to any branch | build.yml | Build + artifact upload |
| PR to main | build.yml | Build + artifact upload |
| Push to main | pre-release.yml | `latest-dev` pre-release |
| Push to feature/* | feature-branch-build.yml | `latest-dev-{branch}` pre-release |
| Tag push (v*) | release.yml | Official release |

## Updater Features

- **Stable channel** — Only official releases
- **Dev channel** — Pre-releases + branch builds
- **Branch matching** — CI records `buildBranch`; dev checks select `latest-dev-{branch}` and compare commits on that branch
- **Auto-install** — Silent install for stable (optional)
- **Manual check** — "Check Now" button in settings
- **Backup/rollback** — Backs up files before install
- **Reload** — Auto-reloads Obsidian after install
