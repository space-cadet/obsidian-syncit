## Decisions Recorded

- A new device must not silently upload local-only files when both sides already contain content.
- First sync needs explicit Remote wins, Local wins, Review, or Cancel choices.
- Ongoing two-way, upload-only, and download-only modes are separate from first-sync authority.
- A device-local sync index is only a performance cache; cross-device deletion requires a shared remote manifest and tombstones.
- Deletions default to reversible trash/review handling; permanent remote deletion requires explicit opt-in.
- ETags, conflict UI, folder-scoped decisions, history, atomic writes, and binary-safe transfers are coordinated through T13 and existing T4/T5/T6/T9/T10/T12d tasks.
