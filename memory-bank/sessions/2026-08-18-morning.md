## Session Notes
### saveSettings() Bug
`saveSettings()` called `indexManager.clear()` on every settings save — even trivial toggles like auto-update. This wiped the sync index constantly, causing full re-uploads every sync (~45 min for 1,700 files).

Root cause of "1710 downloads in dry run": the sync index file was being deleted by `saveSettings()` before the dry run could load it. With no index, ALL files appeared changed.

### .obsidian/ Folder Sync
Cannot sync via `app.vault.getFiles()` — Obsidian API excludes dot folders by design. obsidian-ai uses `app.vault.adapter.list()` for low-level FS access. Would require rewriting VaultScanner — deferred to future session.
